# Research

Answer a question from primary sources: official documentation, specifications, source code, or the source of truth for the claim. Do not accept secondary summaries.

- Cite each claim to its source. A claim without a citation is not a finding.
- Mark what is verified, what is unverified, and where sources conflict.
- When sources conflict, state both and the evidence each rests on. Do not average them.

Write the findings to `<repository-root>/docs/research/YYYY-MM-DD-<topic>.md`. Do not commit the draft.

Use `investigate` instead when the question is about unexpected behavior in this repository: research establishes facts; investigate finds causes.

End every substantive response with `Next:` and one explicit action.
